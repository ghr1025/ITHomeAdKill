# ITHomeAdKill — IT之家去广告 Xposed 模块

针对 IT之家 Android 版（包名 `com.ruanmei.ithome`）的 LSPosed 模块。

## 功能

- Miuix 设置主界面，支持总开关，所有净化规则可独立控制，跟随系统深浅色。
- 首页：关闭轮播，自动刷新可选关闭、1 分钟、5 分钟、10 分钟。
- 文章：关闭 AI 总结、文章打分、打赏与红包区域，不影响正文、评论支持/反对。
- 更多净化：信息流广告、置顶、明确标记的网页推广；广告开关也覆盖已识别的文章底部广告和首页悬浮营销入口。

原有净化选项默认开启；“关闭轮播”“关闭 AI 总结”“关闭文章打分”“关闭打赏与红包区域”默认不启用；自动刷新默认关闭。事件日历使用 IT之家官方“资讯列表设置 → 最新栏目显示事件卡片”控制，模块不再重复拦截。

自动刷新仅作用于**前台、有焦点、当前可见的资讯栏目**。进入文章、后台、其他页面、切换栏目或拖动交互时暂停或重新计时，不刷新预加载的其他栏目、不补跑后台错过的次数。刷新调用应用原有 listener，不额外拼接或访问新闻接口。

## 原理与兼容边界

本模块采用视图级拦截与文章模板的精确 CSS：

1. 精确匹配 `tv_small_tags` 的“广告”/“置顶”，按整卡判断，避免一张卡片中正常标题把广告角标的隐藏结果覆盖。
2. `ll_web` 容器本身不证明是推广。仅同时具有明确广告标记时隐藏，正常或未知网页卡片保留。
3. 首页轮播、文章原生评分、已识别广告入口限制在对应页面与资源结构；重绑前释放模块拥有的折叠，开关关闭时恢复宿主期望的布局状态。
4. 文章 AI 摘要只处理模板 `.ai-abstract`；HTML 评分只处理对应文章评分节点，打赏与红包只处理 `body > .reward` 完整区域。不做“AI”“广告”“打赏”等全文关键词过滤，不改支付逻辑。

当前资源与实机适配基线为 **IT之家 9.55**。未知布局/不可读设置失败开放，不应据此推断已兼容后续所有版本。部分广告是否出现受服务端下发影响，不能把未遇到广告当作拦截命中证据。

## 使用步骤

1. 安装模块 APK。自行编译见 [DEVELOPING.md](DEVELOPING.md)。
2. 在 LSPosed 管理器中启用「IT之家去广告」，作用域仅勾选 IT之家。
3. 从桌面图标或 LSPosed 的模块设置入口打开设置，完成初始化并选择功能。
4. 返回或强制停止后重开 IT之家。设置页的本机保存提示不代表宿主已激活。

## 查看拦截日志

LSPosed 日志或 `adb logcat` 过滤 `ITHomeAdKill`。日志仅记录设置可读状态、选择器状态与刷新事件，不输出文章正文、账户数据或新闻请求。

```sh
adb logcat -s ITHomeAdKill:I
```

`settings=ready:N` 表示宿主读到完整设置版本；`unavailable` 表示未初始化、不兼容或不可读，此时不执行净化/刷新。`native-selector=...` 只表示发现结构，不能单凭它认定广告命中。

## 进阶排查（如果还有漏网广告）

1. 用 `adb shell uiautomator dump` 抓取广告所在页面，找到广告卡片特征
   （角标文字、卡片根 resource-id）
2. 在 `hook/HostRuntime.kt` 中补充有边界的页面/结构识别，并为纯规则补回归测试。
3. 用真实安装的模块与同一内容做开关 A/B，确认正常新闻、评论和复用恢复不受影响。

## 注意

- minSdk 26，需要支持官方 legacy 共享偏好扩展的 LSPosed API 93+。
- 设置只保存功能开关与刷新间隔等非敏感值。共享由框架管理，不手动修改文件权限，不导出自定义设置 Provider。
- 兼容未知或不可读配置时不运行净化；首次使用应打开设置主界面。
- 升级时自动迁移旧配置：移除旧日历控制，新增打赏与红包开关默认不启用，保留其余开关、刷新间隔与配置身份，不重置为默认值。
